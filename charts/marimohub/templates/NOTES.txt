This chart does not install the MarimoSession CRD. Before upgrading this release, update the CRD:
upgrade the marimohub-platform release first, or, if you applied the CRD yourself, run
       kubectl apply --server-side -f deploy/crd/marimosession.yaml

Uninstalling this release first runs a pre-delete hook that foreground-deletes every
MarimoSession and waits for its Pods/Services/Secrets to be gone before removing the operator or
NetworkPolicies; a stuck drain aborts the uninstall rather than leaving orphaned Runtime
credentials behind. The three pre-created namespaces, every existing Secret this chart only ever
references by name, the external database, and the CRD itself are never removed by
`helm uninstall` -- see deploy/README.md for the separate, manual CRD purge step.
